# ADR-0004 插件 hook 只做全局安全、只读、便宜的事

- 状态：已采纳
- 日期：2026-10-13

## 背景
插件里的 hook 会在所有启用该插件的仓库里生效，并与用户、项目自己的 hook 合并。项目特有的检查（lint 命令、测试命令）在不同仓库里完全不同。

## 决策
- 插件只提供 `SessionStart` 的过期提示：只读、不调用 LLM、5 秒超时、出错时无输出且不阻断。
- 项目特有的 sensor 和 gate，由 vic-learn 在目标仓库里生成项目级 hook、lint 规则或 CI 配置，并经用户批准。

## 后果
插件本身不会在陌生仓库里制造噪音；代价是项目级闸门需要逐个仓库建立，这正好符合"失败驱动"原则。
