# 验证、交接与风险边界

质量门应能证明配置与当前任务相符；不要为小改动建立额外编排系统。

## 必需验证

`evaluation` 至少包含：

- `stage_evaluations`：谁验证哪项完成条件，使用什么具体命令或证据。
- `topology_evaluation`：相对于 single-agent，新增角色是否改善证据质量、降低风险或节省独立工作的时间。

配置修改至少检查 TOML 可解析、必需字段齐全、所用字段有当前官方依据、模型与推理设置兼容、引用路径存在，并确认无关设置未被覆盖。语法通过不等于当前 Codex 已加载配置；未验证运行时加载时如实说明。

调研和审查也要验证，但可以使用可追溯来源、具体发现和覆盖范围作为证据。不能确定验证方式时记录 `uncertainty`；仅将阻止必要工作的缺失项记为 `blockers`。

## 证据要求

`evidence_requirements` 按实际角色设置，不为未使用的角色填模板：

| 角色 | 最低证据 |
| --- | --- |
| `implementer` | 分配范围、改动文件、完成声明对应的验证结果 |
| `reviewer` | 具体发现或无发现结论、支撑证据、检查范围与未验证项 |
| `docs-verifier` | 已读取的权威来源、版本敏感细节、事实与推断的区分 |

涉及缺陷时要求复现或等价的失败证据；涉及数据、安全或权限时验证相关边界。审查无发现是有效结果，不强求编造问题。

## 必要时定义交接

真正需要阶段交接时，说明负责人、必要输入、输出工件和接受条件即可。优先交接文件路径、命令结果与明确发现，不依赖另一会话未收到的临时状态。

共享文件系统上的并行工作必须说明写入范围及冲突处理；上下文独立不能用来证明文件隔离。主会话负责综合子代理结果，并核对实际证据。

## 风险边界

`guardrails` 至少保留全局约束；有子代理时补充各角色的必要限制：

- 默认总数为 1–4，包含主会话；并发上限只计算子代理。
- 不因角色模板而扩张写入范围、权限或任务目标。
- reviewer 默认保持只读职责；角色文件中的 sandbox_mode、approval_policy、model_provider、mcp_servers 不覆盖父会话；只读指令不能代替对父运行时和连接器实际权限的检查。
- 不默认递归委派；确有需要时按当前运行时支持及任务边界单独判断，不生成未经当前官方参考确认的深度字段。
- 配置或证据失败时保留原有内容，修复本次目标相关且已授权的问题；未知合同 schema、用户保护角色及无关历史报错保留并报告检查未通过，路由到对应所有者或定向兼容核验。零配置收益优先零写入；必要事实不足只停止依赖该事实的工作。
- 瞬时错误可以有限重试；权限/写入拒绝不是瞬时重试分支。拒绝后保留现场，停止该写分支，不换路径或工具规避，继续独立只读工作；只报告有证据的动作、拒绝原因和实际差异，不从未留存的参数还原补丁。文件未变不证明主动 no-op，回合完成不证明配置成功。

只有任务需要恢复策略时再细分错误类别，不要求每份摘要都生成完整错误处理表。

## 人工确认点

`human_checkpoints` 仅用于当前授权尚未覆盖的破坏性操作、权限扩大或其他实际高风险步骤。沿用已存在的授权；配置生成、普通角色升级、审查和可逆修复本身不要求额外确认。

必要确认点写明动作、原因和未确认时停止的依赖步骤，继续处理不受影响的工作。superpowers 状态为 `unknown` 时跳过可选 bridge，不因此阻塞官方 TOML 配置。

## 交付验收清单

- 已按目录作用域和同目录 `AGENTS.override.md` 优先级读取有效指令。
- 已说明事实来自 `project-context`、`repo-scan` 或 `mixed`；未把 bootstrap 变成硬前置，也未回写单次运行判断。
- 四份核心引用正文均成功读取；读取失败及依赖结论缺口明确报告。来源确实读取、核验日期确实发生；本地快照路径/日期与本轮官方页面 URL/日期分开，未核验不填当天冒充。
- 已区分可用、缺失但相关和计划补充的能力，以及 `mcp` 与 `runtime`；关键 available 有当前可定位证据，可用/允许/已启动/权限已验证分别说明，未为盘点 spawn。
- 每项持久变更均有独立配置收益，未因任务使用量低于项目容量修改上限；合法别名不自动迁移，纯迁移保留数值。
- 已从 single-agent 判断必要性，优先复用内置能力；不需要配置变化时允许零文件变更。
- 已分开 `main_session` 与计划委派的 `active_agents`；代理总数包含主会话，并发子代理数不包含主会话。
- 已遵循 [model-policy.md](model-policy.md) 核验模型与推理设置，用户指定优先，快照超过 45 天先提醒并核验；未从旧示例复制固定模型。
- 已仅增量修改相关官方 TOML，保留无关配置；没有把摘要字段或工具建议当作权限字段。
- 已保留 `minimal_setup`、`enhanced_setup`、`evaluation`、`evidence_requirements` 和 `guardrails`；人工确认点仅对应实际授权缺口。
- 已报告 superpowers 状态；`unknown` 时跳过 bridge，已有授权沿用，未因此阻塞 TOML 工作。
- 如创建 `.codex/AGENTS.md`，已通过适用指令显式引用，并说明它是可选 guidance bridge。
- 已列出实际文件变更、验证证据和未验证项；未将计划角色描述成已运行代理，也未将语法验证描述为运行时加载成功。
- 已运行实际插件的 `vic-check.mjs --agents --root <目标仓库> --json`，结果如实报告；只修本次授权范围，不为零错误改写无关内容。
- 已为发现的旧平行层逐文件提供处置方案，授权未覆盖时保留原件；未误伤 `docs/agents/`。
- 已按实际证据处理角色教训，新增/修改范围与事件关联明确。
- M1 没有写 refresh-log；no-op 没有创建空配置、contracts 或日志。

摘要与说明默认使用简体中文，字段名、路径、模型名和必要技术术语除外。
